# CampusLife

Как запустить приложение CampusLife?


Способ 1. Сразу на телефон (через APK)

1. Скачайте файл .apk из этого репозитория на Android-устройство.
2. Нажмите на него в загрузках. Если телефон попросит разрешение на установку из неизвестных источников — разрешите.
3. Нажмите «Установить» и откройте приложение с экрана (нужен интернет, чтобы подгружались мероприятия из базы).

Способ 2. Через компьютер в Android Studio

1. Скачайте весь проект архивом и распакуйте его.
2. Откройте Android Studio, нажмите Open и выберите распакованную папку с проектом.
3. Подождите пару минут, пока программа сама всё подгрузит и настроит.
4. Запустите эмулятор телефона и нажмите на зеленый треугольник сверху (Run).
